# 본문 분량 편집 기록

## 작업 범위

직전 검토 원고의 과도한 반복과 긴 실행 이력 설명을 압축했다. 새로운 실험, 모델·기준 변경, 수치 재계산, 참고문헌의 외부 검증은 수행하지 않았다.
논문의 절·하위절 구성은 그대로 유지했다. 원격 저장소를 변경하지 않았다.

기준 source commit: `9e9439c7213b5af16eaea79b91d96b6eab2a619c`
원본 Git blob: `53c3417a8332fd50da452ef40c15f8769ae00caa`
로컬 기준 파일을 이 Git blob과 대조하여 완전히 동일함을 확인한 뒤 편집했다.

## 분량

동일한 `texcount -sum -1` 방식으로 main.tex를 측정했다. 외부 그림 및 bibliography의 텍스트는 두 버전 모두 이 계수에 포함하지 않는다.

| 항목 | 편집 전 | 편집 후 |
|---|---:|---:|
| TeXcount 합계 | 10,243 | 8,359 |
| 감축 | | 1,884 (18.39%) |

61개 문단·기여 항목·캡션을 편집했다. 새로운 subsection을 만들거나 결과표를 삭제하지 않았다.
Abstract와 Related Work는 원문을 그대로 유지했다. 방법·결과의 반복 해설과 상세 실행 서술, 마지막 결론·한계의 중복을 주로 압축했다.
최신 에이전트가 정리한 FIFO/타임스탬프, 63-pair 내부 QAT validation, S11 기본 구조 및 S5/S11d 변형, R6 level-1/level-3 구분은 유지했다.

## 보존 검사

| 검사 | 결과 |
|---|---|
| documentclass / preamble / 글자 크기 / 여백 / float 설정 | 변경 없음 |
| 표 환경 전체 | 두 표 모두 원문과 완전 동일 |
| 실험 데이터 행 | 5 + 8 = 13행 보존 |
| citation key 및 각 key의 인용 횟수 | 49개 key와 횟수 모두 동일 |
| 절·하위절 제목과 순서 | 동일 |
| 그림 input/includegraphics 경로·폭 | 동일 |
| 원문에 있던 숫자 문자열의 집합 | 삭제·추가 없음 (천 단위 쉼표 정규화) |
| source의 미정의 교차참조 / 중복 label | 없음 |
| 생성형 AI disclosure | 내용 유지 |

숫자 문자열 검사는 의미 보존의 자동 증명을 뜻하지 않는다. 문단별로 원문의 모델·population·단위·판정 범위를 대조했다. 반복되는 수치 표현은 줄였지만 측정치를 다른 값으로 바꾸지 않았다.

본문 끝의 페이지를 정확히 확인하도록 비인쇄 label `mmsys:body-end` 하나를 추가했다. 이 label은 그림/문자 크기나 지면을 줄이는 명령이 아니다.

## 로컬 지면 점검의 범위와 한계

**완전한 원본 프로젝트의 제출 PDF를 이 환경에서 재생성한 것은 아니다.**
원본 `quad_cam.png`의 바이너리를 GitHub 연결을 통해 작업 컨테이너로 가져오지 못했다. 이 문제를 숨기기 위해 다른 로봇 사진이나 가짜 원본으로 바꾸지 않았다.

확보한 세 TikZ 원본은 Git blob까지 확인했다.
- arch.tex: `e2e63f2c51d6bbe526f49375639edc77c927988d`
- path_a.tex: `6e8d1964e38b97a019630ac028d960aec958677a`
- trade.tex: `5094f1299482c5147fbda9ee04b9ddea950d1a14`

독립된 내부 진단 문서에서만 다음의 보수적인 예약 영역을 사용했다.
- 실제 TikZ 3개와 원래 paired wrapper 사용.
- 첫 사진 대신 200pt 또는 400pt 높이의 명시적 예약 영역 사용.
- 실제 인용을 대체할 참고문헌은 만들지 않음. 지면 검사에서만 인용당 두 자리 폭 표식 사용.
- bibliography 생성은 생략함. 원본 및 배포 main.tex의 bibliography 명령은 변경하지 않음.
- acmart 2.12 (2024/12/28), 기본 Libertine/newtx 폰트, pdfLaTeX 사용.

| 내부 진단 | 본문 및 disclosure 끝 | 비고 |
|---|---:|---|
| 원문, 200pt 사진 예약 | 12페이지 | 비교용 지면 진단 |
| 편집본, 200pt 사진 예약 | 10페이지 | overfull hbox 0; 출력 시 1.486pt vbox 경고 1개 |
| 편집본, 400pt 사진 예약 | 10페이지 | LaTeX 오류 0, overfull hbox/vbox 0 |

400pt 진단 문서 전체 10페이지를 렌더링하여 줄의 겹침, 표 폭, 실제 TikZ 배치를 확인했다. 마지막 disclosure는 10페이지 오른쪽 단에서 끝났다.
이는 감축량에 여유가 있는지 보는 지면 점검이며, 원본 PNG와 실제 bibliography를 넣은 최종 PDF의 페이지 수·인용 해결을 대신하지 않는다.
혼동을 막기 위해 예약 그림/인용 폭 표식이 있는 진단 PDF는 배포 ZIP에 넣지 않았다.

## 실제 제출 PDF 확정

기존 실제 프로젝트에 이 main.tex를 적용한 뒤 정상 전체 빌드를 한 번 수행한다.
첨부 check_build.py는 마지막 .aux에서 `mmsys:body-end` 페이지를 확인하므로,
참고문헌이 11페이지에서 시작한다는 이유만으로 11페이지 위쪽의 본문을 놓치는 오류를 방지한다.
원래 그림과 참고문헌이 있는 환경에서의 실제 PDF와 마지막 로그를 기준으로 최종 분량·익명성을 확인해야 한다.

이번 편집 패키지는 논문 내용의 심사 통과나 모든 외부 증거의 독립 검증을 보증하지 않는다. 기존 미검증 연구 범위는 유지했다.
